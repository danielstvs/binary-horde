# Binary Horde
Projeto inspirado em **Vampire Survivors** que implementa conceitos de estruturas de dados, desenvolvido em **linguagem C** utilizando a engine/biblioteca [Raylib](https://github.com/raysan5/raylib).

## Como Executar o Projeto

1.   **GCC:** O script irá procurar automaticamente pelo GCC no seu sistema. Caso não tenha, instale o [w64devkit](https://github.com/skeeto/w64devkit/releases) e adicione-o ao seu PATH, ou extraia-o diretamente na pasta `tools/w64devkit/` dentro do projeto.

2.   Execute o arquivo `build.bat`.

## Créditos / Template

Este projeto foi desenvolvido utilizando o template do [Prof. Dr. David Buzatto](https://github.com/davidbuzatto), disponível no repositório [Templates-Raylib](https://github.com/davidbuzatto/Templates-Raylib/tree/master).
